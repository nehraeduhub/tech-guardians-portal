// 6-WEEK CURRICULUM

Step-by-Step Modules
Zero to AD Expert

Every module builds on the last. Complete the course and you will be able to deploy, configure, and secure any Active Directory environment — independently.

W1
Windows Server & AD Basics
Windows Server 2019/2022 overview · Install & configure Server roles · What is Active Directory · Domain vs Workgroup · AD components explained · Install AD DS role
W2
Domain Setup & DNS Configuration
Promote server to Domain Controller · Create a new forest & domain · Configure AD-integrated DNS · SRV records & zone types · Join client machines to domain · FSMO roles explained
W3
Users, Groups, OUs & DHCP
Create & manage user accounts · Bulk user import with PowerShell · Security vs distribution groups · OU design best practices · DHCP scope setup · Delegation of Control wizard
W4
Group Policy — Design & Enforcement
Create & link GPOs · Default Domain Policy · Password & lockout policies · Software restriction policies · Drive mapping & folder redirection · GPO inheritance & precedence · Troubleshoot with RSOP
W5
AD Security & Authentication
Kerberos authentication flow · NTLM vs Kerberos · Fine-grained password policies · LAPS — Local Admin Password Solution · AD auditing & event logs · Common AD attacks (Pass-the-Hash, Kerberoasting) & defences
W6
Azure AD & Hybrid Identity
Introduction to Azure Active Directory · Azure AD Connect installation & sync · Password hash sync vs Pass-through Auth · Configure SSO & Conditional Access · Enable MFA · AD backup & disaster recovery
